A ZIP FLIP LINK

This link is meant for an Apple Watch.

Tapped on a watch with Zip Flip installed, it adds the spreadsheet and shows each of its tabs as a deck. You opened it somewhere else, so here is what to do.

On the watch

Install Zip Flip from the App Store on the watch, then tap this link again in Messages.

On a phone or computer

Send this link to the watch in Messages. Nothing to install here.

Open the sheet Send in Messages

If the watch says it cannot read the sheet, check that the sheet is shared as Anyone with the link.
